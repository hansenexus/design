# Wallpapers

Device wallpapers for Mac, iPad and iPhone, one per Focus mode, for hansenexus and for clients.
Every PNG is generated by [`scripts/wallpaper.ts`](../../scripts/wallpaper.ts) from one config per
brand. Do not edit them by hand: change the config and run the generator. `bun run test` fails
while a committed wallpaper is stale (the same contract as `bun run brand`).

```sh
bun run wallpaper               # every brand whose mark sources are on this machine
bun run wallpaper hansenexus    # one brand
bun scripts/wallpaper.ts hansenexus --check   # exit 1 when committed files are stale
```

Output: `brand/wallpapers/<brand>/<ground>-<size>.png`, with a `-draft` suffix while the brand's
config is a draft.

## hansenexus: the Elbe family

Sea-chart contour lines, the same field on every ground, one ground per Focus mode (owner,
2026-11-05, design#122). The mark is flat, in one of the [brand variants](../README.md#variants),
at the bottom centre on the phone (clear of the lock screen buttons) and bottom right elsewhere.
The lines are derived geometry, never an enlarged or outlined mark.

| File | Focus | Ground | Lines | Mark |
| --- | --- | --- | --- | --- |
| `device-hub-*.png` | Device Hub | `brand.ink` | warm 800/750, one line in `brand.lime` ("Fahrrinne") | `lime` |
| `arbeiten-*.png` | Arbeiten | `brand.ink` | warm 800/750, tone on tone | `lime` |
| `buchhaltung-*.png` | Buchhaltung | `brand.paper` | warm 100/200, light | `lime-deep` |
| `steuern-*.png` | Steuern | warm 200 ("Karton") | a shade darker than the ground | `ink` |
| `alltag-*.png` | none | `brand.ink` | warm 850/800, 40 % of the lines | `lime` |

Sizes (`<size>` in the file name):

| Size | Pixels | Device |
| --- | --- | --- |
| `iphone` | 1320 × 2868 | iPhone (portrait) |
| `ipad` | 2752 × 2064 | iPad (landscape) |
| `mac-6k` | 6016 × 3384 | Pro Display XDR |
| `mac-5k` | 5120 × 2880 | Studio Display, 5K |

The Focus profiles in hansenexus/dotfiles#180 set these files by name.

## Clients

This repository is public. Client configs are committed (colours and motif only), but the
clients' logos and the rendered PNGs are not: marks are read from their own repositories at
render time and `brand/wallpapers/<client>/` is ignored by git. A client's tests skip on a
machine without its sources (CI).

| Brand | Status | Mark source | Grounds |
| --- | --- | --- | --- |
| `elbe-akustik` | draft | hn-monorepo `apps/elbe-akustik/public/logo-2025-dark-mark.svg` (the lockup) | `nacht` (Arbeiten), `still` (no Focus) on `--brand-strong` |
| `bargsten` | draft | `~/data/wallpaper-sources/bargsten/logo-mark.traced.svg`, a potrace tracing of hn-monorepo `apps/bargsten/public/logo-mark.png` | `creme` (no Focus), `teal` (Arbeiten) |

elbe-akustik has no light ground: its gold emblem falls below 3:1 on every light surface of the
theme. bargsten has raster logos only; the traced mark is a stand-in until a vector original
exists. Both stay `draft` (files `*-draft.png`) until the owner approves the motif per client.

## Config schema

Types in [`scripts/wallpaper/schema.ts`](../../scripts/wallpaper/schema.ts). Adding a brand is
one new file in [`scripts/wallpaper/brands/`](../../scripts/wallpaper/brands) and one line in
`BRANDS` (`scripts/wallpaper.ts`).

```ts
type BrandConfig = {
  brand: string;                    // folder name under brand/wallpapers/
  status: "approved" | "draft";     // draft: files carry a -draft suffix
  commit: boolean;                  // whether the PNGs are committed (clients: false)
  motif: Contours;                  // the line field, shared by every ground
  mark: {
    variants: Record<string, MarkVariant>;   // the only colourings of the mark
    placement: { portrait: Placement; landscape: Placement };
  };
  grounds: Ground[];                // one wallpaper per ground and size
  sizes: Size[];                    // SIZES: the four device sizes above
};
```

| Type | Fields |
| --- | --- |
| `Colour` | a token path (`"palette.warm.800"`, `"brand.lime"`), `"#rrggbb"` (client configs only; the palette ratchet exempts them), or `{ mix: [a, b, t] }`, a mix in sRGB (a at 0, b at 1) |
| `Source` | `{ root, path }`: `repo` (this repository), `hn-monorepo` (`$HN_MONOREPO`, default `~/repos/hn-monorepo`), `sources` (`$HN_WALLPAPER_SOURCES`, default `~/data/wallpaper-sources`) |
| `MarkVariant` | `file`: a flat SVG (paths and polygons with fills; strokes, gradients, images refused). `fills`: every colour it shows; a file with other fills is refused. `repaint: true` paints every part in the one fill given (for a one-colour mark kept as black artwork) |
| `Placement` | `width` as a fraction of the image width, centre `cx`, `cy` as fractions of width and height |
| `Contours` | `lines`, `amplitude`, `stroke` per layout (lengths as fractions of the image height), `top` and `span` of the field, `segments` per line, `majorEvery` (every n-th line in the `major` colour) |
| `Ground` | `name`, `focus` (the Focus mode, `null` for none), `background`, `line`, `major`, `density` (fraction of the lines), `highlight` (`{ at, colour, weight }`: one accent line), `mark` (a key of `mark.variants`) |
| `Size` | `name`, `width`, `height`, `layout` (`portrait` or `landscape`) |

## Checks

`scripts/wallpaper.test.ts`:

- committed hansenexus PNGs match a fresh render, pixel for pixel;
- every fill of the mark is at least 3:1 against its ground (WCAG 1.4.11), for every brand;
- hansenexus marks come only from the generated `brand/assets/mark/hansenexus-mark-<variant>.svg`
  in their own `brand.<variant>` colour; lime only on dark grounds, lime-deep or ink on light ones;
- a mark file whose fills differ from its config is refused;
- client configs stay `draft` and uncommitted.

Not yet: the dynamic light/dark HEIC for the Mac (Arbeiten/Buchhaltung pair). The PNGs are its
input.
