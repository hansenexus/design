# hansenexus brand: mark and wordmark

The hansenexus mark, the wordmark lockup and the icons made from them. Every file in
[`assets/`](assets) is generated by [`scripts/brand.ts`](../scripts/brand.ts) from one geometry
([`packages/ui/src/brand-geometry.ts`](../packages/ui/src/brand-geometry.ts)) and the `brand.*`
tokens of [`@hansenexus/tokens`](../packages/tokens). Do not edit them by hand: change the
geometry or the tokens and run `bun run brand`. `bun run test` fails while a committed file is
stale.

The name, the mark and the wordmark are trademarks of hansenexus GmbH and are not covered by the
MIT licence of this repository. See [TRADEMARK.md](../TRADEMARK.md).

## The mark

Two flat polygons, taken unchanged from the canonical `logo.svg` (hansenexus/hn-monorepo
`apps/hansenexus/public/logo.svg`, viewBox 422.64 by 321.81).

## Variants

| Variant | Colour (token) | Use on |
| --- | --- | --- |
| `lime` | `brand.lime` (palette lime.500) | ink and other dark surfaces. The default look. |
| `lime-deep` | `brand.lime-deep` (palette lime.700) | paper and other light surfaces, where lime falls below 3:1 |
| `ink` | `brand.ink` (palette warm.900) | paper, lime |
| `paper` | `brand.paper` (palette warm.50) | ink, photographs with a calm dark area |
| `mono` | `currentColor` | anywhere the surrounding text colour is right: navigation, footers, print |

The `brand.*` tokens are the same in both modes: a logo does not follow the theme. The contrast
check covers lime and paper on ink, and ink and lime-deep on paper (3:1, WCAG 1.4.11).

The wordmark uses the same variant names. In `lime` the text is paper (the lockup stands on ink),
in `lime-deep` the text is ink (it stands on paper); the other variants are one colour.

| File | What |
| --- | --- |
| `assets/mark/hansenexus-mark-<variant>.svg` | the mark |
| `assets/wordmark/hansenexus-wordmark-<variant>.svg` | the lockup: mark and `hansenexus` in Fraunces 600, outlined |
| `assets/favicon/favicon.svg` | lime; switches to lime-deep under `prefers-color-scheme: light`, where lime would sit below 3:1 on a light tab strip |
| `assets/favicon/favicon-32.png`, `favicon.ico` (16, 32, 48) | the app icon tile: a PNG cannot switch with the scheme, the tile reads on both tab strips |
| `assets/favicon/apple-touch-icon.png` | 180 px, the app icon tile (opaque, as iOS wants) |
| `assets/app-icon/app-icon-1024.png` | the app icon master: flat, full bleed, the platform applies its own mask |
| `assets/app-icon/app-icon-<kind>-<16,32,1024>.png` | both candidates, for comparison |
| `assets/tray/trayTemplate.svg`, `trayTemplate.png`, `trayTemplate@2x.png` | macOS menu bar template: black plus alpha, the system tints it |

```html
<link rel="icon" href="/favicon.ico" sizes="48x48" />
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />
```

## App icon

Lime mark on the ink tile. Both candidates are rendered at 16, 32 and 1024 px (the gallery's brand
scene shows them side by side). At 16 px the lime mark on ink keeps its two strokes apart and reads
as the brand's own dark surface; the ink mark on a lime tile turns into a lime square with a dark
smudge in a row of other app icons. The mark fills 62.5 % of the tile width, centred.

## Wordmark

`hansenexus`, always lowercase, in Fraunces (the display face of the tokens) at weight 600,
optical size 36, outlined so it looks the same without the font. The mark is as tall as the
ascender of the h and stands on the same baseline; the gap is 0.3 of the mark height. Outlines
come from [`scripts/brand-outline.py`](../scripts/brand-outline.py).

## Clear space

Keep free space of half the mark height on every side of the mark, and half the lockup height
around the wordmark. Nothing else (text, edges, other logos) enters that space.

## Minimum size

| | Minimum on screen |
| --- | --- |
| Mark | 16 px wide (12 px high) |
| Wordmark | 16 px high |

Below that, use the mark alone; below the mark's minimum, use the favicon tile.

## Do not

- Recolour it: only the five variants above. No other colour from the palette or from a theme.
- Add a gradient, sheen, glow, coloured shadow, glass or any effect. The mark is always flat.
- Outline it or draw it as a stroke.
- Rotate, skew, stretch or squash it; scale it only uniformly.
- Redraw it, change the gap, or set the wordmark in another font or in capitals.
- Put lime on paper or other light surfaces: use lime-deep there.

## In code

```tsx
import { HansenexusMark, HansenexusWordmark } from "@hansenexus/ui";

<HansenexusMark size={24} />                          // currentColor, named "hansenexus"
<HansenexusWordmark variant="lime" size={28} />      // on ink
<HansenexusMark variant="lime-deep" aria-hidden />   // decoration next to a visible name
```

Swift: `HansenexusMark(variant: .lime)`, `HansenexusWordmark()` and the bundled files through
`HNBrandAsset` in the `HansenexusBrand` product ([swift/README.md](../swift/README.md)).

Until the packages are on npm, apps vendor `brand/assets/` from a commit of this repository.
